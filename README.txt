MOHAMMED ALTHAF NK — AV PROGRAMMER PORTFOLIO

LOCAL PREVIEW
1. Extract this folder.
2. Open a terminal / Command Prompt inside the folder.
3. Run: python -m http.server 8000
4. Visit: http://localhost:8000

DEPLOYMENT
Upload the contents of this folder to Netlify, GitHub Pages, or another static website host.
The assets folder must remain beside index.html.

CUSTOMIZE
- Update contact details and project descriptions in index.html.
- Replace screenshots in assets/ if you want to use updated project UI images.
- Edit colors and layout in style.css.

NOTE
The project descriptions and credentials are based on the CV provided. Please review all details and contact information before publishing publicly.
